# CODE RUNNER — 바이러스 러너

> 사이버 세상에 갇힌 개발자가 되어, 끊임없이 달려오는 바이러스를 피하고 백신을 획득하며 최대한 오래 살아남는 **3레인 러닝 게임**

바이브 코딩 웹개발 실습 프로젝트입니다. HTML, CSS, JavaScript만으로 동작하는 브라우저 게임입니다.

## 🎮 플레이 방법

1. `index.html`을 브라우저에서 열기
2. **시작하기** → 캐릭터 선택 → 게임 시작
3. 3개 레인(왼쪽 · 가운데 · 오른쪽)을 이동하며 바이러스를 피하고 백신을 수집

### 조작법

| 조작 | 기능 |
|------|------|
| `←` / `A` | 왼쪽 레인으로 이동 |
| `→` / `D` | 오른쪽 레인으로 이동 |
| 모바일 | 좌우 스와이프 |

## ✨ 게임 특징

- **3레인 러너** — Temple Run / Subway Surfers 스타일의 레인 이동
- **목숨 시스템** — 시작 시 ❤️ 5개, 바이러스 충돌 시 1개 감소 (즉사 없음)
- **백신 아이템** — 획득 시 목숨 +1 (최대 5개)
- **난이도 상승** — 시간이 지날수록 속도와 장애물 빈도 증가
- **캐릭터 선택** — 삐아, 오르 중 선택 가능
- **사이버펑크 UI** — 네온 컬러와 코드 레인 배경
- **사운드** — BGM, 효과음, 음량 조절 지원

## 🛠️ 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript
- 외부 프레임워크 없음 — 정적 파일만으로 실행

## 📁 프로젝트 구조

```
├── index.html          # 게임 화면 (시작 · 캐릭터 선택 · 플레이 · 게임 오버)
├── style.css           # 사이버펑크 스타일
├── game.js             # 게임 로직 (레인 이동, 충돌, 점수, 난이도)
├── audio.js            # BGM · 효과음 관리
├── split-sprites.py    # 스프라이트 시트 분할 유틸
├── 기획안.md            # 게임 기획 문서
└── assets/
    ├── sprites/        # 캐릭터 스프라이트 (삐아, 오르)
    └── audio/          # BGM · 효과음 (CREDITS.md 참고)
```

## 🚀 실행 방법

별도 설치 없이 바로 실행할 수 있습니다.

```bash
# 방법 1: 파일 더블클릭
open index.html

# 방법 2: 로컬 서버 (선택)
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```
